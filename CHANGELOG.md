# 📜 Release Notes & Changelog - Version 5.0 (V5)

Release Date: 2026-11-11
Version: v5.0.0

---

## 🌟 Major Enhancements & New Features in V5.0:

### 1. 🎮 Interactive Main Menu Screen
- Completely redesigned start screen featuring interactive clickable buttons:
  - `1 VS 1 Local PvP`
  - `Player VS AI Computer`
  - `Trick Shots & Puzzles Mode`
  - `How to Play & Features`
  - `Exit Game`

### 2. 🏆 Game Over & Victory Screen
- When a match ends (8-Ball pocketed / Puzzle cleared / Win condition met):
  - Displays a Victory Modal Popup announcing the Winner ("PLAYER 1 WINS!", "AI BOT WINS!", etc.).
  - Interactive Action Buttons: `Play Again`, `Main Menu`, `Quit`.

### 3. 🌐 Full English Interface Translation
- Converted all game text, scoreboards, HUD elements, menus, notifications, and instructions to clean English to eliminate any font box issues across operating systems.

### 4. ⏸️ In-Game Pause Menu (`ESC` / Pause Button)
- Pressing `ESC` or clicking the `[PAUSE]` button brings up a dark translucent overlay menu allowing players to:
  - `Resume Game`
  - `Restart Match`
  - `Toggle Table Skin (Theme)`
  - `Return to Main Menu`
  - `Quit`

### 5. 📖 Features & Instructions Visual Guide
- Dedicated in-game guide screen explaining all controls (Aiming, Power Bar, Cue Ball Spin English), game rules, and trick shot puzzle objectives.

### 6. 🚀 One-Click Launcher V5 (`start.py`)
- Automatically checks environment dependencies, offers download options, and boots into the Main Menu.
